  <h3 align="left">👩‍💻  About Me</h3>

  ###

  <p align="left">I’m Natalia, a Senior SDET with 5+ years of experience designing and maintaining test automation frameworks for web,
  mobile and SaaS products.<br><br>
  - 🧪 Building automation in <b>TypeScript</b> with <b>WebdriverIO, Playwright and Cypress</b>, using the Page Object Model on top of
  W3C WebDriver.<br>
  - ✈️ Currently owning end-to-end automation for three international travel booking platforms: bookings, subscriptions and payments
  across web and native mobile.<br>
  - ⚙️ Setting up CI/CD pipelines (GitHub Actions, GitLab CI, Jenkins) and running suites in Docker against Kubernetes-hosted
  environments.<br>
  - 📉 Cut regression cycle time by 30% and manual testing effort by 60% through automation.<br>
  - 🤖 Using AI assistants (GitHub Copilot, Claude) daily for test authoring, flaky-test triage and refactoring.<br>
  - 🎓 ISTQB Certified Tester · MSc in Game Programming (Jagiellonian University).<br>
  - ⚡ Free time = Gaming 🎮 or walking the dog 🐕.</p>
